## 1. 项目概览

### 功能描述

ESP32 通过 WiFi 联网，使用 SSH 协议向远程 Linux 服务器定时上传状态日志。

| 功能 | 说明 |
|------|------|
| **LED 闪烁** | 板载 GPIO 2 (D2) 每秒翻转一次，累计闪烁次数 |
| **日志上传** | 每 10 秒通过 SSH exec 向服务器追加一行日志 |
| **日志格式** | `[闪烁次数: N, 时间: YYYY-MM-DD HH:MM:SS]` |
| **串口报告** | 115200 波特率，实时输出所有运行状态 |
| **自动重连** | WiFi 断开 / SSH 断开自动恢复 |

### 服务器端

| 配置项 | 值 |
|--------|-----|
| **地址** | `<your-server-ip>:22` |
| **用户** | `<ssh-username>` |
| **密码** | `<ssh-password>` |
| **日志路径** | `/path/to/log/dir/esp32_log.txt` |

> 日志在服务器端通过 `echo "..." >> file` 追加写入，无需额外服务端程序。

## 2. 架构设计

### 2.1 为什么用 FreeRTOS 单独任务？

```
┌──────────────────────────────────────────┐
│  Arduino setup()                         │
│    └─ xTaskCreatePinnedToCore(           │
│         controlTask,   ← 入口            │
│         "sshTask",                       │
│         32768,         ← 32KB 栈！       │
│         ...)                             │
│                                          │
│  Arduino loop()                          │
│    └─ vTaskDelay()   ← 空闲，不做工作    │
└──────────────────────────────────────────┘

┌──────────────────────────────────────────┐
│  FreeRTOS: sshTask (Core 0, 32KB 栈)     │
│                                          │
│  ┌─ SPIFFS 挂载（known_hosts 存储）      │
│  ├─ WiFi 连接                            │
│  ├─ NTP 时间同步                         │
│  ├─ libssh_begin() 初始化                │
│  ├─ SSH 连接 + 认证                      │
│  └─ while(1) 主循环:                     │
│       ├─ LED 闪烁 (每 1s)                │
│       ├─ 日志上传 (每 10s)               │
│       └─ WiFi 断线检测                   │
└──────────────────────────────────────────┘
```

> **关键原因**：LibSSH 的加密握手（DH 密钥交换、RSA/ECDSA 签名验证）需要大量栈空间（~20KB+）。  
> Arduino 默认 `loop()` 任务栈仅约 8KB，会导致 **Stack overflow → Guru Meditation** 崩溃。

### 2.2 数据流

```
ESP32                             远程 Linux 服务器
──────                             ─────────────────────
LED 闪烁 (GPIO2)
  │
  ├─ 计数 blinkCount++
  │
  ├─ 每10s ─── SSH exec ───►  echo "[...]" >> /root/esp32/esp32_log.txt
  │               ▲
  │               └─ 检查退出码 == 0 才认为成功
  │
  └─ 串口 115200 实时输出状态
```

## 8. 运行流程详解

### 8.1 启动阶段

```
1. setup()
   ├─ Serial.begin(115200)
   ├─ pinMode(LED_PIN, OUTPUT)
   └─ xTaskCreatePinnedToCore(controlTask, ..., 32768, ..., Core 0)

2. controlTask() 在新任务中执行（大栈空间）
   ├─ SPIFFS.begin(true)          ← 存储 known_hosts
   ├─ connectWiFi()                ← 15 秒超时
   ├─ syncTime()                   ← NTP 同步，10 秒超时
   ├─ libssh_begin()               ← 初始化 SSH 库
   └─ connectSSH()
        ├─ ssh_new()
        ├─ ssh_connect()           ← TCP + SSH 握手
        ├─ verify_knownhost_auto() ← 首次自动保存主机密钥
        ├─ authenticate_password() ← 键盘交互 + password 认证
        └─ mkdir -p /root/esp32    ← 确保远程目录存在
```

### 8.2 运行阶段（每 100ms 循环一次）

```
while(1):
  │
  ├─ [每 1s]  blinkLED()
  │     └─ digitalWrite(LED_PIN, !state), blinkCount++
  │
  ├─ [每 10s] uploadLog()
  │     ├─ 组装日志: "[闪烁次数: N, 时间: YYYY-MM-DD HH:MM:SS]"
  │     ├─ 转义特殊字符
  │     ├─ sshExecCommand("echo \"...\" >> /root/esp32/esp32_log.txt")
  │     │    ├─ ssh_channel_new()
  │     │    ├─ ssh_channel_open_session()
  │     │    ├─ ssh_channel_request_exec()
  │     │    ├─ 循环读取 stdout + stderr 直到 EOF
  │     │    └─ 检查退出码 == 0 → 成功
  │     └─ 失败 → 重连 SSH → 重试一次
  │
  └─ [持续]  检测 WiFi 断开 → 重连
```

### 8.3 SSH 连接生命周期

```
                    ┌──────────┐
          ┌────────►│ 已连接   │◄─────────┐
          │         └────┬─────┘          │
          │              │ 断开/错误       │
          │         ┌────▼─────┐          │
          │         │ 断开旧连接 │          │
          │         └────┬─────┘          │
          │              │                │
          │         ┌────▼─────┐   失败    │
          └─────────│ 重新连接  ├──────────┘
                    └──────────┘
```

> SSH 会话在启动时建立并**持久保持**，不每次上传都重新连接。

## 9. 核心函数参考

### 9.1 控制流

| 函数 | 说明 |
|------|------|
| `setup()` | Arduino 入口，创建 FreeRTOS 任务 |
| `loop()` | 空闲，仅 `vTaskDelay()` |
| `controlTask()` | 主工作任务，包含全部业务逻辑 |

### 9.2 网络

| 函数 | 返回值 | 说明 |
|------|--------|------|
| `connectWiFi()` | `bool` | 连接 WiFi，15 秒超时 |
| `syncTime()` | `void` | NTP 时间同步，10 秒超时 |
| `getCurrentTimeStr()` | `String` | 返回 `"YYYY-MM-DD HH:MM:SS"` |

### 9.3 SSH 核心

| 函数 | 返回值 | 说明 |
|------|--------|------|
| `connectSSH()` | `bool` | 建立持久 SSH 连接 + 认证 |
| `disconnectSSH()` | `void` | 断开 SSH 连接并释放资源 |
| `sshExecCommand(cmd)` | `bool` | 执行远程命令，检查退出码 |
| `verify_knownhost_auto(session)` | `int` | 自动验证/保存主机密钥 |
| `authenticate_password(session, pw)` | `int` | 密码认证（kbdint → password） |

### 9.4 业务逻辑

| 函数 | 说明 |
|------|------|
| `blinkLED()` | 翻转 LED，累加 `blinkCount` |
| `uploadLog()` | 组装日志行 → SSH exec echo 追加 |
| `reportStatus(msg, isError)` | 带时间戳的串口输出 |

### 9.5 `sshExecCommand()` 关键细节

```cpp
// ✅ 正确做法（v2.1）：
ssh_channel_request_exec(channel, command);

// 循环读取直到远程端关闭（收到 EOF）
while ((nbytes = ssh_channel_read(channel, buf, sizeof(buf)-1, 0)) > 0) { ... }
while ((nbytes = ssh_channel_read(channel, buf, sizeof(buf)-1, 1)) > 0) { ... }

// 获取退出状态
int exit_status = ssh_channel_get_exit_status(channel);
// exit_status == 0 → 成功

// ❌ 错误做法（v2.0）：
ssh_channel_send_eof(channel);  // 不应该在 exec 模式发送 EOF！
ssh_channel_close(channel);      // 命令可能还没执行完
return true;                     // 没检查退出码！
```

## 10. 关键技术决策

### 10.1 为什么用 SSH exec 而不是 SCP？

| 方案 | 优点 | 缺点 |
|------|------|------|
| **SSH exec** ✅ | 一次连接持久复用；天然支持追加（`>>`）；一条命令即可 | 需要转义特殊字符 |
| SCP | 适合传输完整文件 | 每次上传需重新 SCP 会话；追加需先读后写 |
| HTTP POST | 简单 | 需要额外服务端程序；非 SSH |

### 10.2 为什么用 FreeRTOS 独立任务？

- Arduino `loop()` 默认栈 ~8KB，不足以支撑 SSH 加密握手
- LibSSH-ESP32 官方示例全部使用独立 FreeRTOS 任务（16KB~40KB 栈）
- 本项目的 32KB 栈经验证足够稳定

### 10.3 为什么用 SPIFFS？

- LibSSH-ESP32 的 `known_hosts` 机制需要持久存储
- SPIFFS 是 ESP32 内置闪存文件系统，无需外接 SD 卡
- 自动格式化：`SPIFFS.begin(true)` 首次自动创建

### 10.4 为什么用 `echo "..." >> file` 追加？

- 远程 shell 原生支持，无需安装任何服务端软件
- SSH exec 直接执行，一步完成
- 需转义 `"` `` ` `` `$` 防止 shell 解释

## 11. 故障排查

### 11.1 Guru Meditation: Stack canary watchpoint

```
原因：SSH 操作栈溢出
解决：确保使用 FreeRTOS 任务且栈 ≥ 32768 字节
检查：setup() 中是否用了 xTaskCreatePinnedToCore()
```

### 11.2 SSH 连接失败

```bash
# 从本机测试 SSH 是否可达
ssh <user>@<your-server>

# 检查 ESP32 WiFi 是否连接
# 串口应输出: WiFi 连接成功！IP: x.x.x.x
```

### 11.3 上传"成功"但服务器没有文件

```
原因：sshExecCommand() 未等待命令完成 / 未检查退出码
确认：当前版本 v2.1 已修复此问题
验证：串口应显示 "上传成功 ✓"，且服务器上 cat 文件有内容
```

### 11.4 闪存空间不足

```bash
# 清理编译缓存
rm -rf ~/.cache/arduino/

# 清理后重新编译
arduino-cli compile --fqbn esp32:esp32:esp32 --clean
```

### 11.5 串口无输出 / 乱码

```bash
# 确认波特率
arduino-cli monitor -p /dev/ttyUSB0 -c baudrate=115200

# 检查串口权限
ls -la /dev/ttyUSB0
groups $USER | grep dialout
```

### 11.6 编译错误：multiple definition of `_impure_ptr`

```
原因：在 .ino 中重复定义了 _impure_ptr
解决：删除自定义的 _impure_ptr 定义，LibSSH-ESP32 已内置
```
