## 1. 硬件速览

### 1.1 驱动板

| 项目 | 详情 |
|------|------|
| 型号 | Waveshare E-Paper ESP32 Driver Board |
| 版本 | CH343 串口芯片版（2022.7 后新版） |
| WiFi | 802.11b/g/n (2.4G) |
| 蓝牙 | BLE 4.2 |
| Flash | 4MB |
| 开发方式 | Arduino / ESP-IDF |

### 1.2 墨水屏

| 项目 | 详情 |
|------|------|
| 型号 | 5.83inch e-Paper (V2) |
| 类型 | 黑白（单色） |
| 分辨率 | **648 × 480** |
| 驱动芯片 | EPD_5in83_V2 |

### 1.3 引脚映射（固定，无需改动）

| 功能 | ESP32 引脚 | 说明 |
|------|-----------|------|
| SCK | GPIO 13 | SPI 时钟 |
| MOSI (DIN) | GPIO 14 | SPI 数据 |
| CS | GPIO 15 | 片选，低有效 |
| DC | GPIO 27 | 数据/命令选择 |
| RST | GPIO 26 | 复位，低有效 |
| BUSY | GPIO 25 | 忙碌状态指示 |

### 1.4 硬件开关

| 开关 | 位置 | 说明 |
|------|------|------|
| **1号 (Display Config)** | **A** (0.47R) | 5.83/7.5寸必须拨到 A |
| **2号 (USB to UART)** | **ON** | 烧录程序必须 ON |

> 显示异常时可尝试将 1 号开关拨到另一侧。

## 4. 快速开始

### 4.1 确认硬件连接

```bash
# 检查驱动板是否识别
ls /dev/ttyACM* /dev/ttyUSB*

# 确认芯片型号
export PATH="$HOME/.local/bin:$PATH"
arduino-cli board list
```

### 4.2 基于模板创建新项目

```bash
# 复制模板
cp -r project-template/ ~/esp32/projects/我的新项目/
cd ~/esp32/projects/我的新项目/

# 重命名 .ino 文件（必须与文件夹同名）
mv template.ino 我的新项目.ino

# 修改 arduino.json 中的 sketch 名称
# 然后编译烧录
arduino-cli compile --fqbn esp32:esp32:esp32
arduino-cli upload --fqbn esp32:esp32:esp32 -p /dev/ttyACM0
```

### 4.3 一键编译烧录

```bash
cd ~/esp32/projects/我的新项目/
bash /path/to/dev-tools/upload.sh
```

## 5. 项目模板

### 5.1 最小项目结构

```
我的项目/
├── 我的项目.ino        ← 主程序（必须与文件夹同名）
├── ImageData.h         ← 图片数据声明
├── ImageData.cpp       ← 图片数据（C数组）
└── .vscode/
    └── arduino.json    ← 板卡配置
```

### 5.2 .ino 模板骨架

```cpp
#include "DEV_Config.h"
#include "EPD.h"
#include "GUI_Paint.h"
#include "ImageData.h"
#include <stdlib.h>

void setup() {
    DEV_Module_Init();
    EPD_5in83_V2_Init_Fast();   // 快速刷新模式

    UBYTE *BlackImage;
    UDOUBLE Imagesize = ((EPD_5in83_V2_WIDTH % 8 == 0) ? (EPD_5in83_V2_WIDTH / 8) : (EPD_5in83_V2_WIDTH / 8 + 1)) * EPD_5in83_V2_HEIGHT;
    BlackImage = (UBYTE *)malloc(Imagesize);

    Paint_NewImage(BlackImage, EPD_5in83_V2_WIDTH, EPD_5in83_V2_HEIGHT, 0, WHITE);
    Paint_SelectImage(BlackImage);
    Paint_Clear(WHITE);

    // === 在此绘制 ===
    Paint_DrawBitMap(gImage_custom);  // 显示图片
    // Paint_DrawString_EN(10, 10, "Hello", &Font16, BLACK, WHITE);
    // ================

    EPD_5in83_V2_Display(BlackImage);
    EPD_5in83_V2_Sleep();
    free(BlackImage);
}

void loop() {}
```

### 5.3 常用绘图 API

```cpp
// 基本图形
Paint_DrawPoint(x, y, BLACK, DOT_PIXEL_1X1, DOT_STYLE_DFT);
```

### 5.4 初始化模式选择

| 函数 | 用途 |
|------|------|
| `EPD_5in83_V2_Init()` | 全刷（标准模式） |
| `EPD_5in83_V2_Init_Fast()` | 快速刷新 |
| `EPD_5in83_V2_Init_Part()` | 局部刷新模式 |
| `EPD_5in83_V2_Init_4GRAY()` | 4级灰度模式 |

## 6. 图片显示

### 6.1 图片要求

| 参数 | 说明 |
|------|------|
| 输入格式 | PNG / JPG / BMP 等常见格式 |
| 输出分辨率 | 648 × 480 px（自动缩放） |
| 输出格式 | 1-bit 黑白，Floyd-Steinberg 抖动 |
| 缩放策略 | 等比缩放宽度至 648，上下居中留白 |

### 6.2 转换步骤

```bash
# 1. 把图片放到方便的位置

# 2. 编辑 dev-tools/convert_image.py，修改 INPUT 路径
#    INPUT = "/path/to/your/image.png"

# 3. 运行转换（用系统 Python，避免 ESP-IDF 虚拟环境冲突）
/usr/bin/python3 /home/cedar/esp32/epaper/E-Paper_ESP32_Driver_Board_Code/dev-tools/convert_image.py

# 4. 生成的 ImageData.h / ImageData.cpp 会放入目标项目目录
# 5. 编译烧录
```

### 6.3 自定义缩放策略

编辑 `convert_image.py` 中的缩放部分：

```python
# 方案 A：等比缩放，居中留白（默认）
ratio = W / img.width
new_h = int(img.height * ratio)
img_resized = img.resize((W, new_h), Image.LANCZOS)
canvas = Image.new("L", (W, H), 255)
y_offset = (H - new_h) // 2
canvas.paste(img_resized, (0, y_offset))

# 方案 B：拉伸填满全屏
img_resized = img.resize((W, H), Image.LANCZOS)
canvas = img_resized

# 方案 C：等比缩放，填满高度，左右留白
ratio = H / img.height
new_w = int(img.width * ratio)
...
```

## 7. 常用命令速查

```bash
# === 环境 ===
export PATH="$HOME/.local/bin:$PATH"    # 每次新终端先执行

# === 编译 ===
arduino-cli compile --fqbn esp32:esp32:esp32              # 标准编译
arduino-cli compile --fqbn esp32:esp32:esp32 --clean      # 清理重编

# === 烧录 ===
arduino-cli upload --fqbn esp32:esp32:esp32 -p /dev/ttyACM0

# === 编译+烧录一步 ===
arduino-cli compile --fqbn esp32:esp32:esp32 -u -p /dev/ttyACM0

# === 串口监视 ===
arduino-cli monitor -p /dev/ttyACM0 -c baudrate=115200

# === 板卡信息 ===
arduino-cli board list                # 已连接板卡
arduino-cli board listall esp32       # 所有ESP32板卡

# === 库管理 ===
arduino-cli lib list                  # 已安装库
```

## 8. WiFi / 蓝牙 无线刷图

### 8.1 WiFi 模式

1. 打开 `Loader_esp32wf/srvr.h`
2. 修改 WiFi 名称和密码：
   ```cpp
   const char *ssid = "你的WiFi名";
   const char *password = "你的WiFi密码";
   ```
3. 修改静态 IP（与电脑同网段）：
   ```cpp
   IPAddress staticIP(192, 168, 1, 159);
   IPAddress gateway(192, 168, 1, 1);
   ```
4. 编译烧录 `Loader_esp32wf.ino`
5. 串口监视器查看 ESP32 获取的 IP 地址
6. 浏览器打开该 IP，即可通过网页上传图片

### 8.2 蓝牙模式

1. 编译烧录 `Loader_esp32bt/Loader_esp32bt.ino`
2. 手机安装 `app-release.apk`（在项目根目录）
3. APP 中连接蓝牙 → 选择型号 → 选图 → 上传

## 9. 故障排查

| 问题 | 解决方案 |
|------|----------|
| 显示"一条杠" | 确认用了 V2 驱动（`EPD_5in83_V2_Init`），不是老版 |
| 烧录失败 `Timed out waiting for packet header` | 出现 "Connecting..." 时按住驱动板 BOOT 键 |
| 找不到 `/dev/ttyACM0` | 检查 USB 线、2号开关是否 ON、`lsusb` 确认设备 |
| 编译报错 `imagedata.h not found` | Linux 大小写敏感，改为 `#include "ImageData.h"` |
| `python3` 找不到 PIL | 用 `/usr/bin/python3` 代替 `python3` |
| 显示效果异常 | 尝试切换 1 号开关（A↔B） |
| Arduino CLI 找不到命令 | `export PATH="$HOME/.local/bin:$PATH"` |
